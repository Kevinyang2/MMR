# English annotation sample

`qv_m2_test_en_100.jsonl` contains the first 100 non-empty records from the
local `data/QV-M2/test.jsonl`, preserved without field or value changes. It is
provided solely as a small English-language demonstration input for the video
annotation tool.

Each JSONL line describes a query/video pair and may include fields such as
`qid`, `vid`, `query`, `duration`, `relevant_windows`, and
`relevant_clip_ids`. The sample does not include the referenced videos.

## Provenance

- QV-M2 project: <https://github.com/Zhuo-Cao/QV-M2>
- Paper: *When One Moment Isn't Enough: Multi-Moment Retrieval with
  Cross-Moment Interactions* (NeurIPS 2025)
- QV-M2 builds on the QVHighlights video collection and annotation format.
